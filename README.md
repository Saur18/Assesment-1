## Steps to Run the Application
## 🔧 Backend (ASP.NET Core API)

1. Open the solution AvalphaTechnologies.CommissionCalculator in Visual Studio.
2. Run the API project. Swagger is enabled for testing endpoints.

## 🌐 Frontend (Angular UI)

1. Navigate to the angular-ui directory.
2. Run npm install to install dependencies.
3. Start the Angular app using ng serve. It will run on http://localhost:4200.
4. Submit the form and inspect the Network tab in DevTools to verify API calls and responses reflected on the UI.
